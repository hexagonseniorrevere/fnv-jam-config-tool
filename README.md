## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Module Toggle** | Enable or disable each JAM component independently |
| **Sprint Settings** | Adjust AP cost and speed multiplier for JAM sprinting |
| **Stealth Config** | Tune JAM's stealth sneak meter and detection tweaks |
| **Loot Menu** | Configure JAM's ground loot menu appearance and hotkeys |
